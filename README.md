# ESP32C3 WIFI

This repository is an example for establishing wifi connection with DHCP on ESP32C3.
This was forked from: https://github.com/esp-rs/esp-hal/blob/main/examples/wifi/embassy_dhcp/src/main.rs with some correction based on latest version of ESP-HAL & ESP-RADIO

## Running

To run:
```bash
cargo run
```
